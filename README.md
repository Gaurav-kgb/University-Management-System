# University-Management-System
Full-stack University Management System | React.js | Core Java | REST API | JDBC | MySQL | CRUD Operations | DAO Architecture

## 🚀 Getting Started

### Prerequisites

Make sure the following software is installed on your system:

* Java JDK 17 or later
* Node.js (v18+ recommended)
* MySQL Server 8.0+
* Git
* IntelliJ IDEA or Eclipse (Backend)
* Visual Studio Code (Frontend)

---

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Gaurav-kgb/University-Management-System.git
cd University-Management-System
```

> **Note:** Replace `University-Management-System` with your actual repository name if it is different.

---

## 🔌 REST API

The backend exposes a custom REST API that communicates with the React frontend using HTTP.

**Architecture**

```text
React Frontend
      │
      │ HTTP Requests
      ▼
Core Java REST API
      │
      ▼
Business Logic
      │
      ▼
DAO Layer (JDBC)
      │
      ▼
MySQL Database
```

The application follows a layered architecture:

* **Presentation Layer** – React.js frontend
* **API Layer** – Core Java REST API
* **Business Logic Layer** – Request processing and validation
* **Data Access Layer** – DAO classes using JDBC and Prepared Statements
* **Database Layer** – MySQL

This architecture improves modularity, maintainability, and scalability.
